Willkommen! 

In diesem Repository finden Sie die Datensätze und R-Skripte, auf die wir im Rahmen des Seminars Bezug nehmen.

Sie benötigen R und RStudio, um damit zu arbeiten (Anleitung und Link zum Download s. Moodle). Sie benötigen **keinen GitHub-Account** und müssen GitHub auch nicht installieren.

---

## 📥 Kursmaterialien herunterladen

### Zu Beginn des Semesters

Um alle Kursmaterialien herunterzuladen:

1. Klicken Sie oben auf den grünen Button **`Code`**.
2. Wählen Sie **`Download ZIP`**.
3. Speichern Sie die ZIP-Datei auf Ihrem Computer.
4. Entpacken Sie die ZIP-Datei.

Anschließend finden Sie einen Ordner mit allen Kursmaterialien auf Ihrem Computer.

---

## 📂 Das R-Projekt öffnen

Im heruntergeladenen und entpackten Ordner befindet sich eine Datei 
```text
seminar-protest-in-autokratien.Rproj
```

Doppelklicken Sie auf diese Datei. Das Kursprojekt sollte sich anschließend automatisch in **RStudio** öffnen. 

---

## 🗂️ Ordnerstruktur

Die wichtigsten Ordner in diesem Repository sind:

* 📁 **`code`** – enthält die R-Skripte, mit denen wir arbeiten.
* 📁 **`daten`** – enthält die für den Kurs benötigten Datensätze.
* 📁 **`visualisierungen`** – enthält Visualisierungen und Abbildungen.

---

## ▶️ Mit dem Code arbeiten

Öffnen Sie das R-Projekt über die `.Rproj`-Datei. Anschließend können Sie in RStudio den Ordner **`code`** öffnen und das entsprechende R-Skript auswählen.

---

## 🔄 Aktualisierungen während des Semesters

Im Laufe des Semesters werden möglicherweise neue R-Skripte, Datensätze oder Visualisierungen ergänzt.

Wenn neue Materialien bereitgestellt werden, erhalten Sie entsprechende Informationen.

Je nach Aktualisierung werden Sie entweder:

* eine einzelne neue Datei herunterladen oder
* die aktuelle Version des gesamten Repositorys erneut herunterladen.
